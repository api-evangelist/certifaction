# Certifaction

> Certifaction is a privacy-first digital signature platform. Its "Zero Document Knowledge" model hashes and end-to-end-encrypts documents client-side, so documents can be signed (SES, AES, and Qualified Electronic Signatures) without Certifaction ever seeing their content. Integration is via a client-hosted CLI / Local API and an Admin API.

This llms.txt was generated by the API Evangelist enrichment pipeline from the provider's public developer surface and the artifacts in this repository.

## APIs
- [Certifaction Local API](https://developers.certifaction.com/en/references/api): Client-hosted proxy API to prepare, sign, request, verify, download, and revoke documents locally. Production platform host: https://api.certifaction.io
- [Certifaction Admin API](https://developers.certifaction.com/en/references/admin-api): Organization, user, role, and team-space administration.
